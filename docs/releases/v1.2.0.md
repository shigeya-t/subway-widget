# 東京地下鉄運行情報 1.2.0

都営地下鉄と東京メトロの次発時刻・残り時間と運行状況を、メニューバーとデスクトップのウィジェットに出しておく macOS アプリです。
今回から、自分でビルドしなくても DMG から入れられるようになりました。

## インストール

1. DMG を開き、**東京地下鉄運行情報** を **Applications** フォルダへドラッグします。
2. アプリケーションフォルダから **東京地下鉄運行情報** を起動します。Dock には出ず、メニューバーに次発までの残り時間が出ます。
3. デスクトップを右クリック →「ウィジェットを編集」→ **東京地下鉄運行情報** を選んで配置します。
4. 置いたウィジェットを右クリック →「ウィジェットを編集」で、事業者 → 路線 → 駅 → 方面 を選びます。
5. 常用するなら、システム設定 →「一般」→「ログイン項目」に登録してください。時刻表と運行状況はアプリが取得してウィジェットに渡します。

**動作条件:** macOS 14 以降、インターネット接続。

## できること

- **都営4路線・東京メトロ9路線** — 駅はカタログから選ぶので、APIキーの登録は不要です。
- **次発時刻と残り時間** — その後の数本も表示。本日分が終わったら翌日の始発に切り替えます（平日 / 土曜 / 日曜・祝日を明示）。
- **運行状況** — Yahoo!路線情報と同じ「平常運転 / 遅延」。
- **ウィジェット（小・中）** — クリックすると、その路線の運行情報ページを開きます。

## ご注意

- **以前に自分でビルドして入れていた場合は、先にそちらを削除してください**（`~/Applications/東京地下鉄運行情報.app` など）。同じアプリが 2 か所にあると、ウィジェットがプレースホルダのままになることがあります。配布版は自前ビルドと App Group が異なるため、選んでいた駅・方面は引き継がれません。
- **非公式のデータ取得です。** Yahoo!路線情報の公開ページを取得して解析しています。サイト側の変更で突然取れなくなることがあります。
- 残り時間は在線位置ではなく **定刻 − 現在時刻** です。遅延時は運行状況で知らせ、時刻そのものは定刻のまま出します。
- 詳しい使い方は [README](https://github.com/shigeya-t/subway-widget#readme) を参照してください。
